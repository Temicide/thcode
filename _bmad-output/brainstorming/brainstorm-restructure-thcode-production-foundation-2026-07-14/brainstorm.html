01 / Question Storming

Trust begins before execution.

What must the project structure answer before it can be trusted in production?
↗

Approval has two depths

Lead with a plain-language purpose. Expand to exact arguments, destination, selected data and side effects. For local execution, show the exact command.

⇄

Remote calls remain inspectable

Preview method, verified endpoint, service and safe payload summary. Credentials never enter the display.

!

Evidence before explanation

The harness classifies network failure; the model explains it. Users may inspect the deterministic category and sanitized raw evidence.

◷

One round, one clock

Total end-to-end prompt duration is the user-facing unit. Subsystem timings and token distinctions stay available to developers.

02 / Constraint Mapping

Own the harness.
Bound the blast radius.

thcode cannot guarantee an upstream model’s judgment. It can guarantee a polished TUI, reliable execution, visible risk, and persistent boundaries.

declared permission boundary

Full Access ≠ no boundary. Workspace, command, network, service and quota scopes remain declared; sensitive transfer is still a separate override.

03 / Backcasting

Start from “connected.”
Walk backward to the contract.

The future state is an extension ecosystem that grows without rewriting the UI—or its neighbors.

Available to useHEALTHY / DISCOVERED

Live health check

A configured model appears only after its API responds. Availability proves connectivity—not tool-call compatibility.

Generic discovery

The TUI renders registered metadata through reusable components. New providers and services require zero extension-specific UI.

Named protocol profiles

OpenAI-compatible and Anthropic for reasoning; declarative HTTP mappings for specialist services; reviewed adapters where protocols do not fit.

Configuration without code

After installation, users may add Ollama, vLLM, private OCR or speech endpoints. Configuration maps fields and endpoints; it cannot execute custom adapter code.

Reviewed product surface

Slash commands remain TypeScript shipped by thcode developers. Extension freedom stops short of arbitrary executable code.

04 / Failure Analysis

Do not guess after the signal breaks.

A production foundation earns trust by preserving uncertainty, making broken states explicit, and reversing only what it can prove.
